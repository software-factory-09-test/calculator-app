# TanStack Start Template

Canonical starter application for interactive frontend generation in Factory Studio.

## Language

**TanStack Start App**:
A full-stack type-safe React web application powered by TanStack Start and Vite.
_Avoid_: Single page app, create-react-app, nextjs app

**Route Component**:
A file-based React component defining a page or layout within the TanStack Start application router.
_Avoid_: Page view, view template
